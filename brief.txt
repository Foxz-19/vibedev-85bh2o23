Caffeine Diary: Coffee Tasting Log
Build a single-page coffee tasting journal that lets users log every cup they try and remember what made it great (or terrible).

Each entry should capture:
- **Coffee name** (e.g. "Ethiopian Yirgacheffe")
- **Roaster / café** name
- **Brew method** (dropdown: espresso, pour-over, French press, cold brew, etc.)
- **Rating** (1–5 stars, clickable)
- **Tasting notes** (short free-text field for flavour descriptors like "chocolatey", "bright acidity", "smoky")
- **Date tried** (auto-filled to today, editable)

The main view shows a scrollable card list of all logged coffees, sorted by most recent. Each card displays all fields at a glance and has an edit and delete button.

Add a compact **stats bar** at the top showing: total coffees logged, average star rating, and the user's single highest-rated entry (name + rating).

All data must persist in `localStorage` so the log survives a page refresh. No sign-in, no backend — just a slick, coffee-themed UI that a caffeine lover would genuinely want to use every morning.
